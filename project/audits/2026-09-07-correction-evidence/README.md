# Preuves locales du lot A01–A18

Ces fichiers sont copiés du bundle local `/tmp/galaris-a18-bundle` après son upgrade,
sa restauration, ses 48 E2E et ses scans. Les images sont identifiées par leur contenu.
Leurs fichiers ne sont pas ajoutés au dépôt.

`SOURCE_COMMIT` précise qu'il s'agit du **worktree non commité**, basé sur `15881f3c`,
et non d'une release issue de ce commit. Les champs `tests_commit` désignent la base Git
des tests ; `tests_sha256` ajoute l'empreinte des scripts de qualification exécutés.
La promotion d'un tel bundle est refusée. Ces preuves ne remplacent pas une nouvelle
qualification après commit ni l'essai depuis l'image réellement déployée.

Le [rapport des corrections](../2026-09-07-postcommit-corrections.md) conserve les
résultats des suites, les mesures, le périmètre des simulations et les limites restantes.
