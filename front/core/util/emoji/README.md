# Document tag icon catalogues

Generated by `front/scripts/generate-tag-icon-catalog.mjs` from:

- `emojibase-data@17.0.0`: Unicode emoji, names and search terms (MIT; LICENSE.emojibase).
- Installed `@quasar/extras@2.0.3`: MDI v7.4.47 and Font Awesome Free v7.3.1 font glyph names.
- `front/core/util/solaire.ts`: the shared folder palette.

Run inside the development frontend container, with the extracted emojibase package
mounted read-only and `back/` mounted at `/back`:

    node scripts/generate-tag-icon-catalog.mjs /emoji-data

This also regenerates `back/app/memory/icon_catalog.json`, the server's builtin allowlist.
Unicode emoji use the device's emoji font. There are no bundled SVG emoji illustrations.
The two icon fonts are provided locally by Quasar Extras, with their upstream licenses:
https://pictogrammers.com/docs/library/mdi/getting-started/license/
https://fontawesome.com/license/free

Each catalogue and each Unicode translation is a separate deferred module. The font
catalogues contain glyph names, not SVG paths. Common French search synonyms enrich
the technical names supplied by the font libraries.
